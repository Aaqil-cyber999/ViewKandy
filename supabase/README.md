# Database setup

KandyVerse uses **Drizzle ORM** as the source of truth for the PostgreSQL
schema. Supabase provides Postgres, Auth and Storage; the catalogue is read and
written on the server through Drizzle.

## 1. Configure

```bash
cp .env.example .env.local
# Set DATABASE_URL to the Supabase pooler/direct connection string
```

Use the **session-mode pooler** on port `5432` (or the direct connection) for
migrations. The transaction pooler on `6543` also works for the app at runtime.

## 2. Create the schema

```bash
npm run db:bootstrap   # extensions schema + PostGIS + storage bucket
npm run db:migrate     # applies drizzle/*.sql
npm run db:seed        # upserts data/seed/*.json through Drizzle
```

Or all three at once:

```bash
npm run db:setup
```

`db:bootstrap` is idempotent. It also ensures the `extensions` schema is on the
connection role's `search_path`, which the generated `geography` column needs.

## 3. Verify

```bash
npm run db:check       # prints server version, search_path, extensions, tables
```

## Changing the schema

```bash
# edit lib/db/schema.ts
npm run db:generate    # writes a new SQL migration to drizzle/
npm run db:migrate
```

Do not edit the generated SQL by hand. If you need a Supabase-managed object
(auth FK, storage policy), use the scripts in this folder.

## Optional: auth foreign keys

`auth-fk.sql` adds database-level FKs from `favorites`/`itineraries` to
`auth.users`. Drizzle cannot declare a reference into the Supabase-managed
`auth` schema, so this is applied separately when you want the extra guarantee.
RLS policies are already generated by Drizzle and protect these tables.

## Seed data rules

Every seeded place is `unverified` with `null` opening hours, fees and phone
numbers. Verification is only shown when an editor records a source URL and a
verification date in `/admin`. Do not “fix” the seed data with invented facts.

## Files

| Path | Purpose |
| --- | --- |
| `lib/db/schema.ts` | Drizzle tables, checks, indexes and RLS policies |
| `lib/db/client.ts` | Server-only pool + Drizzle client |
| `lib/db/drizzle-store.ts` | Typed catalogue queries and verification audit |
| `drizzle/` | Generated SQL migrations + metadata |
| `supabase/seed.sql` | Optional SQL seed for the Supabase SQL editor |
| `supabase/auth-fk.sql` | Optional FK to `auth.users` |
